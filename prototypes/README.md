# Stupid Suite — Prototype Lab & UX Experiments

---

## 1. Purpose
The Prototype Lab serves as the experimental design sandbox prior to writing production code.
We validate:
- **Design Systems:** Modernized Win98 vs. Google Workspace Minimalist vs. Serious Hybrid.
- **Ergonomics:** Inline keyboard editing, cell density, mobile viewport behaviors.
- **Micro-Interactions:** Web Audio sound effects, slider responsiveness, 1-click bridge triggers.

---

## 2. Active Prototypes
- **`design-exploration/ui_direction_comparison.html`**: Interactive side-by-side study comparing UI directions with live Web Audio, margin calculators, and Flow prompt generators.

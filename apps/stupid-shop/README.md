# Stupid Shop — Omnichannel Commerce & Voice Presets

---

## 1. Core Purpose
`Stupid Shop` manages multi-channel product publishing (Shopify, Etsy, Stand POS) and enforces the brand's distinct voice while safeguarding listings against automated payment or marketplace censorship.

---

## 2. Key Modules
- **Shopify Direct Sync:** Publish descriptions, variants, and high-res sliced images directly via GraphQL.
- **Etsy Optimizer:** Automatic category taxonomy mapping and 13-tag SEO title optimization.
- **Stand POS:** Clean touch interface for artisan market booths and festivals with rounded card/cash checkout.
- **Anti-Censorship Semantic Shield:** Automated rewrite layer that scans product descriptions for trigger terms (e.g., piercing terminology, leather terms, specific keywords flagged by Stripe or Etsy bots) and replaces them with safe, compliant luxury synonyms.
